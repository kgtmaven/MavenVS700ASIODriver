# kgtmaven's Roland/Cakewalk SONAR V-STUDIO 700 ASIO Driver

${\color{red}WARNING! \space Use \space At \space Your \space Own \space Risk!}$

This project provides a new ASIO driver for the abandoned Roland/Cakewalk SONAR V-STUDIO 700 (VS-700), <br>
which is no longer supported due to the end of support for Roland.

The final official driver version of the VS-700R has poor ASIO compatibility with some programs, <br>
causing crashes or operational failures, especially in OBS Studio. This new driver fixes those problems.

## Installation
Just click Download Zip, extract the files, and run "Install.bat" with administrator privileges.

## Uninstallation
run "Uninstall.bat" with administrator privileges.
